Barcode-Bild (drucken & aufkleben)

Beim Anlegen eines neuen Markers wird das Barcode-Bild automatisch hochgeladen. „Zum Upload vormerken“ erzwingt einen erneuten Upload (z. B. wenn die Datei im Repo fehlt).

Bild-Panel (Anleitungstafel)

Tipp: PNG mit Alpha-Kanal, Querformat ca. 1600×1000 px passt zu 0.8×0.5 m.

3D-Modell

Format: .glb empfohlen. Das Modell bleibt aufrecht und dreht sich um die Hochachse.

Anleitungstext (Overlay am Handy)

Vorschau (schematisch)

Kamera / Erkennung

Achtung: Barcode-Bilder und Typ müssen zusammenpassen. Die mitgelieferten Marker sind 3x3_HAMMING63 (0–7). Bei Wechsel auf 3x3 (0–63) müssen alle Barcode-Bilder neu erzeugt werden.

Overlay-Verhalten
QR-Code

Der QR-Code wird beim Speichern als qr/qr-code.png hochgeladen und ersetzt den auf der Desktop-Seite angezeigten Code.

GitHub-Zugang

Empfehlung: feingranularer Token (Settings → Developer settings → Fine-grained tokens), nur für dieses Repository, Berechtigung Contents: Read and write, sinnvolle Ablaufzeit. Der Token wird ausschließlich im localStorage dieses Browsers gespeichert – er wird nie ins Repository geschrieben oder an Dritte übertragen.
